EA Signals redesign

7 แบบให้เลือก แต่ละแบบมี popup หน้าหลัก, Watchlist, Settings และ panel บนกราฟ ข้อมูลในภาพเป็นตัวอย่าง (MOMO มาจาก screenshot จริง ที่เหลือแต่งขึ้น)

  • ARefinedระบบเดิม (ดำ-ขาว) จัดใหม่ให้อ่านง่ายขึ้น เสี่ยงน้อยที่สุด
  • BPrice Ladderสีแบบ TradingView กลืนกับกราฟ วาดไม้ที่ถืออยู่เป็นบันไดราคา: ตอนนี้ / ราคาซื้อ / stop
  • CChecklistธีมสว่าง เน้นช่วงรอเข้า: ผ่านกี่ข้อแล้ว และขาดอะไรอีกเท่าไหร่
  • DRadarเปิด popup แล้วเห็นทุกเหรียญก่อน เรียงตามสิ่งที่ต้องทำ บนกราฟเหลือแค่ปุ่มเม็ดเล็ก
  • ELight Radar (C + D)หน้าตาสว่างของ C จัดแบบ Radar ของ D: เปิดมาเห็นทุกเหรียญเป็นการ์ด แท็บนี้กางเป็น checklist เต็ม บนกราฟเป็นปุ่มเม็ดสว่าง
  • FDark Gate (D + C)พื้นดำของ D เอา gate ของ C ขึ้นเป็นตัวเด่น: "2/3" ตัวใหญ่ แต่ละช่องบอกค่าจริง ใต้ลงมาเป็นรายการเหรียญอื่นแบบย่อ
  • GGate, dark / light (F + E)โครงของ F ใช้ฟอนต์และปุ่มเม็ดบนกราฟแบบ E มีปุ่มสลับธีมมืด / สว่าง
