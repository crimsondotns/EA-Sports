## #3: ขายทีละ 10% เมื่อ RSI ≥ 80

| | |
|---|---|
| ขนาดไม้ | 10% ของพอร์ต |
| Stop | −20% จากราคาเข้า · หลังขายครั้งแรก stop เลื่อนมาที่ราคาเข้า |
| ขาย 10% | ทุกแท่งที่ปิดด้วย RSI(14) ≥ 80 และราคาปิดสูงกว่าราคาเข้า ขายที่ราคาเปิดของแท่งถัดไป (แท่งติดกันก็ขายแท่งละ 10%) |
| เก็บฟรี | ขายจนเหลือ 10% แล้วเก็บไว้ ขายทีละ 1/3 ที่ 10x / 30x / 100x |
| Time stop | ถือครบ 30 วันจริงแล้วยังไม่เคยขาย → ขายที่ราคาปิด |

**จุด Confirm การขาย:** แท่งที่ปิดด้วย RSI ≥ 80 เหนือราคาเข้า → ขาย 10% ที่ราคาเปิดแท่งถัดไป
**บนกราฟ:** ลูกศรเหลือง **SELL 10% +x%** และเส้น **STOP**

## #1: คืนทุน 3x

| | |
|---|---|
| ขนาดไม้ | 10% ของพอร์ต (New Launch 5%) |
| Stop | −20% จากราคาเข้า |
| คืนทุน | high แตะ 3x ของราคาเข้า → ขายพอได้ทุนคืน เก็บไว้ฟรี 10% |
| หลังคืนทุน | trailing stop 35% ใต้ราคาปิดสูงสุด (ไม่ต่ำกว่าราคาเข้า) |
| เก็บฟรี | ขายทีละ 1/3 ที่ 10x / 30x / 100x |
| Time stop | ถือครบ 30 วันจริงแล้วยังไม่ถึงคืนทุน → ขายที่ราคาปิด |

**บนกราฟ:** ลูกศร **COST BACK**

## ราคาที่ขายได้จริง

| ออกเพราะ | ตรวจเมื่อ | ขายที่ |
|---|---|---|
| Stop / trailing | low แตะหรือต่ำกว่าเส้น stop | ราคา stop · ถ้าเปิด gap ต่ำกว่า stop ขายที่ราคาเปิด |
| คืนทุน 3x / 10x / 30x / 100x | high แตะระดับนั้น | ราคาระดับนั้น · ถ้าเปิดเหนือกว่า ขายที่ราคาเปิด |
| Time stop | ครบ 30 วันจริง | ราคาปิด |

- แท่งเดียวแตะทั้ง stop และเป้าขาย → นับว่าโดน stop ก่อน
- Trailing stop ตามราคาปิดสูงสุด (ไม่ใช่ high) และขยับขึ้นอย่างเดียว
- Time stop นับเป็นวันจริง ไม่ใช่จำนวนแท่ง เพราะช่วงที่ไม่มีคนเทรดจะไม่มีแท่ง
