# Volume Breakout

ซื้อตอนราคาทะลุ high พร้อม volume พุ่ง · **ไม่แนะนำ** (ลงเต็มพอร์ต ขาดทุนหนัก) · โค้ด `src/strategy/volumeBreakout.ts`

## ซื้อเมื่อ (ครบ 5 ข้อบนแท่งเดียว)

1. **ทะลุ:** ราคาปิดสูงกว่า high สูงสุดของ 20 แท่งก่อนหน้า
2. **Volume พุ่ง:** ≥ 2.5 เท่าของค่าเฉลี่ย 20 แท่ง
3. **Volume ขั้นต่ำ:** ≥ $1,000
4. **ขาขึ้น:** ราคาปิดเหนือ EMA 50
5. **ไม่ไล่ราคา:** ราคาปิดสูงกว่า EMA 20 ไม่เกิน 15%

## จุด Confirm

แท่งที่ผ่านครบปิดแล้ว → **ซื้อที่ราคาเปิดของแท่งถัดไป**

## ขาย

| | |
|---|---|
| ขนาดไม้ | 100% ของพอร์ต |
| Stop | ราคาเข้า − 2 × ATR |
| Trailing | ราคาปิดสูงสุด − 3 × ATR (ขยับขึ้นอย่างเดียว) |
| Time stop | ถือครบ 96 แท่ง |

## ผล backtest

40 เหรียญ: 15m กำไร 10/40 ค่ากลาง −99.6% · 1h 8/40, −75.5% · 4h 14/37, −3.2%

## บนกราฟ

เส้น **BUY ABOVE** ที่ high สูงสุดของ 20 แท่ง และ volume ขั้นต่ำที่ต้องการ
